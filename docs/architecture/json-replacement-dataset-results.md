## Сравнение с текущим режимом

- **JSON-планы**: полностью правильных запросов не меньше — да; точность действий не ниже — да; полнота не ниже — да; медиана и p95 не выше — да. Изменение общего расхода токенов: -0.2% экономии; тарифной оценки: +14.2% экономии.

## Границы измерения

Ожидания исходного датасета не менялись. Использован прежний ActionMatcher; в основной оценке эквивалентные моменты времени приводятся к часовому поясу пользователя. Архивный балл без этой нормализации сохранён в поле legacyCorrect. Неудачные обращения не исключаются из общей доли правильных запросов.

Задержка измеряется для планирования: чтение контекста, обращения к Groq, исправления и выполнение песочницы. Распознавание аудио, внешний туннель и браузер сюда не входят; VOICE_TRANSCRIPT — готовый текст.

Тарифная оценка использует 0.15 USD за миллион входных и 0.60 USD за миллион выходных токенов по [публичному тарифу Groq](https://console.groq.com/docs/model/openai/gpt-oss-120b). Скидки за кеширование и инфраструктура не учтены; это расчёт по usage, а не счёт поставщика. Для отклонённого API ответа usage может быть неизвестен.

Это сравнение полных реализаций: на результаты влияют и формат плана, и инструкции, и объём кандидатов, и интенсивность рассуждений. Экономию нельзя целиком приписывать JSON или Code Mode. Набор использовался при доработке; выводы о новых неизвестных командах потребуют отдельного отложенного набора.
