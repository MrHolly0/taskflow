## Границы измерения

Ожидания исходного датасета не менялись. Использован прежний ActionMatcher; в основной оценке эквивалентные моменты времени приводятся к часовому поясу пользователя. Архивный балл без этой нормализации сохранён в поле legacyCorrect. Неудачные обращения не исключаются из общей доли правильных запросов.

Задержка измеряется для планирования: чтение контекста, обращения к Groq, исправления и выполнение песочницы. Распознавание аудио, внешний туннель и браузер сюда не входят; VOICE_TRANSCRIPT — готовый текст.

Тарифная оценка использует 0.15 USD за миллион входных и 0.60 USD за миллион выходных токенов по [публичному тарифу Groq](https://console.groq.com/docs/model/openai/gpt-oss-120b). Скидки за кеширование и инфраструктура не учтены; это расчёт по usage, а не счёт поставщика. Для отклонённого API ответа usage может быть неизвестен.

Это сравнение полных реализаций: на результаты влияют и формат плана, и инструкции, и объём кандидатов, и интенсивность рассуждений. Экономию нельзя целиком приписывать JSON или Code Mode. Набор использовался при доработке; выводы о новых неизвестных командах потребуют отдельного отложенного набора.

## Изменения реализации

Версия кода: 0944600. Для JSON выделены отдельные инструкции: поисковый select разрешается сервером после ответа, поэтому отсутствие задачи среди 12 кандидатов не требует создания нового дела или отказа. Добавлены примеры выбора между существующим и новым делом, перечислений и работы с искажёнными названиями.

В JSON проверка полей отклоняет весь невалидный план, а не возвращает только удачные действия. Модель получает одну попытку исправить ошибки полей или ссылки; обе попытки входят в токены и задержку. Перед исправлением сбрасывается ошибка прежней отклонённой выборки, но не счётчик поисков. Code Mode и DIRECT в этом этапе не дорабатывались.

## Ограничения результата

В основном сравнении выполнен один повтор на каждый режим. Предыдущая версия трёх режимов проверялась тремя повторами; её результаты сохранены в planning-results.md отдельно и не смешиваются с текущими. Изменение 83,6 до 88 процентов нельзя интерпретировать как точную причинную оценку доработки: изменились повтор и условия обращения к поставщику.

Сохранились ошибки дат, приоритета, пропуски смешанных команд и нестабильность на искажённых расшифровках. Некоторые категории уступают DIRECT: даты — 18/20 против 19/20, изменение существующих — 12/15 против 13/15. Неоднозначность улучшилась до 9/15 против 7/15 DIRECT, но отдельные безопасные уточнения расходятся со старой разметкой, требующей update без новых значений или переноса без указанного срока. Ожидаемые ответы не исправлялись и не исключались.

Из пяти отказов API в основном сравнении четыре пришлись на DIRECT, один на JSON; все остались в знаменателях. Сравниваются полные реализации с разными инструкциями, контекстом и интенсивностью рассуждений. Обобщение на другие модели, нагрузку и реальные голосовые записи этим прогоном не подтверждено.

По общим метрикам JSON проходит заданный ориентир: качество выше DIRECT, токенов меньше, медиана и p95 ниже. Режим оставлен экспериментальным. По умолчанию продолжает работать DIRECT; публичный стенд не переключался.

Требуется отдельная доработка; автоматическое переключение продукта не выполнялось. На прежних шести инъекциях — 6/6, медиана 415 мс, p95 803 мс.

Новые обычные тесты проверяют исправление полей без потери остальных действий, отсутствие частичного результата после двух невалидных попыток, восстановление после пустой выборки и сохранение лимита восьми поисков между попытками. Полная Java-регрессия: 965 тестов, без ошибок и пропусков.
