# Исполнитель планов

Code Mode использует отдельный Node-процесс с QuickJS/WASM. Код модели исполняется внутри QuickJS, не через Node `eval` или `vm`. Доступен только `api.findTasks(selector)` и `api.now`; файловая система, сеть, импорты, переменные окружения и запись в БД не предоставляются.

Принимается тело async-функции или выражение `async () => { ... }`; оба формата исполняются только внутри QuickJS. Функция вызывается один раз.

Обмен с ядром — ограниченные JSON-кадры stdin/stdout. Идентификатор пользователя остаётся в ядре и не задаётся программой. Каждый вызов создаёт новый runtime; данные и глобальные объекты между пользователями не сохраняются.

Ограничения: 16 КиБ исходника, 16 МиБ памяти QuickJS, стек 256 КиБ, до 1 секунды исполнения движка и 3 секунд на весь процесс, максимум 8 выборок и 20 предлагаемых действий. Размер результата ограничен 32768 символами. Одновременно ядро запускает один исполнитель. Дополнительно Node ограничен кучей 64 МиБ; это не лимит всей памяти процесса. Общий предел памяти задаётся контейнером ядра.

```bash
cd code-runtime
npm ci --ignore-scripts
npm test
```

Ключи API для исполнения не нужны. Ошибка, превышение лимита или неоднозначная выборка не превращаются в произвольное изменение задач: ядро возвращает уточнение. Если программа поймает ошибку небезопасной выборки, весь результат всё равно отклоняется ядром.
